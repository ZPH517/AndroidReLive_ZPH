这台设备拒绝了电脑模拟点击：鼠标、键盘、唤醒都用不了
小米 / 红米 / POCO：设置 → 更多设置 → 开发者选项 → 打开「USB 调试（安全设置）」→ 重启手机 → 重新连接
1. 手机先登录小米账号、插一张能用的 SIM 卡、保持联网；Wi-Fi 验证不过就换移动数据。
2. 设置 → 更多设置 → 开发者选项（没有这一项：在「我的设备 / 关于手机」里连点「OS 版本 / MIUI 版本」7 次）。
3. 打开「USB 调试（安全设置）」；顺手把「USB 安装」也打开，网页里装 APK 要用它。
4. 重启手机 —— 不重启开关不生效，这是最容易漏的一步。
5. 重新插线、解锁，弹「允许 USB 调试」时勾「一律允许」再确定。
6. 回来点「断开」再「连接设备」，按右边「验证是否已开启」；不报错就成了，最后把「主屏镜像」关掉重开一次。
开关置灰 / 提示设备受限：多半是账号或 SIM 卡没满足条件，或小米服务器临时限流，等一会儿再试，反复点没用。
未连接
Android 11+ 手机：开「无线调试」→ 点「一键发现设备」→ 输 6 位码，以后都能直接连。
老手机 / 智能电视 / 盒子：开「ADB 调试（网络调试）」→ 点「扫局域网」→ 设备屏幕上点一次「允许」。
最稳、且兼容所有安卓版本：插一次数据线 → 点「USB 一键开启无线」，之后永久免线。
电脑与设备需在同一 Wi-Fi / 局域网
